# Rock Paper Scissors 

An interactive **Rock Paper Scissors** game built with HTML, CSS, and JavaScript, where users play against a computer opponent.

## Features

* Player vs. computer gameplay
* Randomized computer choices
* Automatic win, lose, and draw detection
* Score tracking
* Interactive user interface
* Restart/reset functionality

## Technologies Used

* HTML
* CSS
* JavaScript

## How to Play

1. Choose **Rock, Paper, or Scissors**.
2. The computer randomly selects its choice.
3. The game determines the winner based on the rules.
4. Scores are updated after each round.
5. Continue playing or reset the game to start again.
